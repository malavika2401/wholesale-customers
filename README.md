# wholesales customers
Description :
    This project focuses on analyzing the Wholesale Customers dataset. The dataset contains
    information about customers and their annual spending on different product categories.
Dataset Features:
     The dataset includes customer spending information such as:
        1.Fresh
        2. Milk
        3.Grocery
        4.Frozen
        5.Detergents_Paper
        6.Delicassen
        7.Channel
        8.Region
Objective:
        The main objective of this project is to:
             1.Analyze customer purchasing patterns.
             2.Identify similarities and differences between customers.
             3.Understand spending behavior across product categories.
             4.Apply data analysis or machine learning techniques to the dataset.
Technologies Used:
        1.  Python
        2.  Pandas
        3.  NumPy
        4. Matplotlib
        5.  Seaborn
        6.  Jupyter Notebook
